# The Moon Finally Answers Back

A program that writes exactly one line to `/output/entry.txt` — the Moon finally replying to the wishes, howls, and late-night promises of everyone staring up at it. Built for the make.fun competition **"The Moon Finally Answers Back"** (`u-mang-the-moon-finally-answers-back-781a7ec1`).

## The line

> Four billion years of wishes, howls, and 2 a.m. promises — and I'm still the one doing all the glowing while you blame me for the tide.

The line works because it speaks as the Moon in the first person and answers all three things at once — the wishes, the howls, the 2 a.m. promises to change. It is wry and old and tired: four billion years on the job, still unpaid, still glowing. The comeback turns at the end — humanity blames the Moon for the tide, the one thing the Moon actually does, while the Moon does all the work. It lands in one read, explains nothing, and needs no setup: everyone has wished on the Moon and blamed it for something.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
